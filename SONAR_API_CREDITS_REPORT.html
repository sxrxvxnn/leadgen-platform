Company prefill — searches for the company's LinkedIn URL by domain (site:linkedin.com/company domain.com). Funding data — searches Crunchbase/TechCrunch for funding rounds. Similar companies — queries site:g2.com and site:capterra.com to pull competitor names from search snippets. G2 and Capterra are accessed through these Brave queries — no separate G2 API key needed.
2,000 queries/month free.

Called from enrichment.py and company_prefill.py.
500 scrapes/month free.

Discovery

PDL Prospect Search · 700M+ people · SQL filters by title, company, location, size · scroll_token pagination
API / ServiceWhat it does in DiscoveryPricing / Free tierCost per use
People Data Labs (PDL)Prospect search
Powers the entire Prospect page. User sets filters — job title keywords, company size, location, seniority — and the backend converts them into a PDL SQL query. Returns matching profiles with name, title, company, location, email (where available), LinkedIn URL, and work history. Scroll token pagination means page 2, 3, etc. do not re-bill the page 1 matches. The proprietary sonar_contacts table (built by the daily enrich cron) is always searched first — profiles found there are returned for free.
$0.05–$0.10 per matched profile.
No free tier for person search.
Cached contacts served free.
Scroll token avoids re-billing.
$0.05–$0.10per new match
Sonar Contacts DBInternal cache
Proprietary contact table (sonar_contacts) built by the daily enrich-contacts cron using Brave Search + Groq. Checked before every PDL query — profiles found here are served instantly at zero cost. Reduces PDL spend as the table grows.
Free. Internal Supabase table.
Grows daily via cron.
$0.00Internal DB

Leads

LinkedIn capture via extension · Email finding (Hunter → Apollo waterfall) · ICP scoring · DM generation · Engagement tracking
API / ServiceWhat it does in LeadsPricing / Free tierCost per use
Groq LLMllama-3.3-70b
ICP scoring — given a lead's name, title, company, and about text alongside the user's ICP criteria, Groq returns a score 0–100 and a one-sentence reason using a structured rubric. Bulk scoring processes up to 50 leads per call. DM generation — writes a personalised LinkedIn cold outreach message tailored to the lead's role and company context.
14,400 TPM free · 1K req/day.
~120 tokens per ICP score.
~800 tokens per DM.
$0.00Within free tier
Hunter.ioEmail finder — primary
Email finding — given a lead's first name, last name, and company domain, Hunter returns the most likely verified email address and the domain's email pattern (e.g. first.last@company.com). Used on the Email Finder page and when enriching a lead record. First in the waterfall — tried before Apollo.
25 searches/month free.
Starter: $49/month · 500 searches.
Growth: $99/month · 2,500 searches.
25 free/mothen $49/mo
Apollo.ioEmail finder — fallback
Email finding fallback — automatically tried when Hunter.io returns no result for a lead. Apollo has a broader database of direct-dial numbers and emails, especially for US companies. Part of the waterfall: Hunter → Apollo → pattern-based guess.
50 email exports/month free.
Basic: $49/month · 1,200 exports.
Tried only when Hunter fails.
50 free/mothen $49/mo
ProxyCurlLinkedIn person data
Deep lead enrichment — fetches the lead's full LinkedIn profile: current and past work history, education, skills, connections count, and profile photo URL. Called when user clicks "Deep Enrich" on a lead. More comprehensive than what the extension captures from the DOM.
$0.01 per person lookup.
No free tier for person API.
$0.01per deep enrich
Chrome ExtensionLinkedIn DOM scraper
Captures lead data from LinkedIn profile pages — name, headline, current title, company, location, and profile URL — by reading the page DOM. User clicks "Save to Sonar" in the popup or inline button. No external API call — runs entirely in the browser.
Free. MV3 content script.
No external calls.
$0.00Browser only
Email Tracking PixelOpen + click tracking
Self-hosted tracking — the backend serves a 1×1 GIF pixel embedded in sent emails. When a recipient opens the email, the pixel loads and the backend records the open event, incrementing the lead's engagement_score by +3 on first open and +5 on first link click. No external API.
Free. Self-hosted endpoint.
/track/open/{id} and /track/click/{id}.
$0.00Self-hosted
